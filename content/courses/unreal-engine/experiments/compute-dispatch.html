Compute dispatch, coverage, and bounds

A browser model of a two-dimensional compute dispatch. Dispatch arguments count thread groups; numthreads determines invocations per group. Each cell is an invocation. The colored valid rectangle is the output image; excess cells are rounded-up invocations that need a bounds check. This is not a GPU performance simulator.

Blue: valid write. Orange: guarded excess invocation. Red: invalid write attempt. Empty output cells: uncovered.

Predict, change, explain

Set the group width to 8 and use a 17 × 10 output. Predict group counts and excess invocations. Turn rounding upward off, then turn the guard off. Explain why these cause different problems.
