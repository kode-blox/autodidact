Start from familiar application responsibilities: inspect an input, change it, hand it to another component, and coordinate shared work. Learn how Rust expresses those responsibilities through ownership, borrowing, `Arc`, and `Mutex`.

This course assumes programming experience. Its initial two lessons focus on the decisions behind function signatures and shared state, with small standard-library programs you can run and deliberately change to test your understanding.
